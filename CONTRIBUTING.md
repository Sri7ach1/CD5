# Contributing to CD5

Thank you for your interest in improving CD5!

CD5 is an open-source PlayStation 5 homebrew Audio CD player developed
by Sri7ach1. Contributions, forks, bug reports and feature suggestions
are welcome.

## Ways to contribute

You can help with:

- Improving playback performance and stability
- Testing additional USB optical drives
- Testing other PS5 firmware and homebrew environments
- Improving the user interface and karaoke rendering
- Improving metadata, artwork and lyrics handling
- Fixing bugs
- Improving documentation
- Reviewing dependencies and license compliance
- Making the build process easier to reproduce

## Forks and pull requests

1. Fork https://github.com/Sri7ach1/CD5
2. Create a branch for your improvement
3. Make your changes
4. Test them where possible
5. Open a pull request describing what changed

Pull requests are welcome. Please explain any hardware or firmware
configuration used for testing.

## Bug reports

When reporting a bug, please include:

- PS5 model and firmware version
- Homebrew/jailbreak environment
- USB optical drive manufacturer and model
- CD5 version
- Steps to reproduce the issue
- Expected and actual behavior
- Relevant logs, if available

Do not include private credentials or identifying information in logs.

## Code and licensing

Contributions to original CD5 code should be submitted under the project's
GPL-3.0-or-later license.

Do not submit proprietary SDK files, copyrighted third-party code without
the required permissions, private credentials, or binaries of uncertain
redistribution status.

Please preserve applicable third-party copyright and license notices.

## Development status

CD5 is currently in beta development.

The existing native build requires external tools and runtime components.
See the README for the current requirements and limitations.
